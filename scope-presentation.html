🎯 JavaScript Scope

Understanding Identifier Scope & Resolution

Learn how JavaScript finds variables in your code

What is Scope?

Scope determines where variables are accessible in your code.

JavaScript has two main types:

  • Global Scope: Variables accessible everywhere
  • Local Scope: Variables accessible only inside a function

How JavaScript Finds Variables

When you use a variable, JavaScript searches in this order:

1️⃣ Local scope (inside the function) 2️⃣ Global scope (outside the function)

This is called "Identifier Resolution"

Example 1: Using Global Variables

const name = "Alice"; // Global function greet() { console.log(name); // No local name, uses global } greet();
Output: "Alice"

✓ Function found the global variable

Example 2: Local Shadows Global

const name = "Alice"; // Global function greet() { const name = "Bob"; // Local (same name!) console.log(name); // Which one? } greet();
Output: "Bob"

✓ Local variable takes priority (shadows global)

Example 3: Scope Isolation

const color = "red"; // Global function paint() { const color = "blue"; // Local console.log(color); // Output: "blue" } paint(); console.log(color); // Output: "red"
Function output: "blue"
Global output: "red"

✓ Changes inside function don't affect global

The Original Problem

const num = 103; // Global function example(num) { // Parameter named num console.log(num); // Uses PARAMETER } example(50);
Output: 50

✓ Parameter shadows the global variable

Key Takeaways 🎓

  • JavaScript searches inside the function first
  • If not found, it searches in global scope
  • Local variables shadow (hide) global ones with the same name
  • Function parameters work like local variables
  • Changes in local scope don't affect global
